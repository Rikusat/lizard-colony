## 2. 各要素の描画方式(既存資産の流用)

- **背景**: canvas。radialGradient ビネット+決定論ハッシュ(既存 `h2` イディオム)でセル状斑点(小さな radialGradient×N・低α)。現行 `#nest-scroll` のCSS radial背景を置換。guardCtx 配下(全canvas自動)。
- **巣+卵**: canvas。枝=円環に沿う bezier ストローク束(下層=太/暗、中層=中間、上層=細/ハイライトの3層を位相ずらしで交差=**疑似織り**)。卵=radialGradient+決定論斑点+ハイライト。葉=小楕円を疎らに。光暈=radialGradient(既存 genesisFx/提灯グローと同法)。
- **糸**: canvas。1糸=quadraticCurve 2〜3本の低α束(座標由来の揺れ=決定論)+輝点(小arc+shadowBlur)。**スアミ(traitSuami)の網糸・結節と同じ視覚言語**=流用。現行のSVG線は canvas へ置換(比較を1枚絵で測るため)。
- **ノード**: **DOM 続投**(現行 `.wnode` を拡張: 二重リム/ラベルピル/解放率/条件文)。アイコンは `Icon.svg` をそのまま使える(canvas化だと Path2D 変換の工数が大きい→回避)。彩色は報酬鉱石色(oreById)から導出=データ駆動。
- **右パネル/ヘッダ/ヒント**: DOM(UISkills カード様式・既存トークン)。数値は実データ(nestWebCounts 等)のみ・捏造しない(モックの Lv.12 等は見本値)。
- **構成**: 背景+巣+糸=canvas 1枚(`#nest-canvas`)、ノード/パネル=DOM を上に重ねる**ハイブリッド**。比較は「見たまま」=CDPページスクショで測る(§5 方式B)ため混在でも測定可能。

## 3. 技術的に困難な箇所と代替表現(省略しない)

1. **編み枝の織り質感** — 手続きで「編み目」を出すのが最難。代替: 3層ストローク束の位相交差(疑似織り)+枝端のはみ出し数本+接地影。B1で先行制作し数値+目視ゲートに最初に掛ける。
2. **糸の繊維感** — 単線では硬い。代替: 低α多重曲線+輝点+太さの揺らぎ(全て座標由来=決定論)。
3. **ノード内アイコングリフ** — canvas 再現は高コスト。代替: DOMで `Icon.svg` 流用(モックのグリフと意匠差が出る場合は §5 で「アイコン領域低重み」+目視ゲート)。
4. **フォント差** — モックのフォントと実装フォント(Zen Kaku 等)の画素差は避けられない。代替: 比較でテキスト領域を低重み/除外(アノテーションで領域指定)。
5. **左カラム** — 対象外提案(§1-9)。含める判断なら+1セッション。
