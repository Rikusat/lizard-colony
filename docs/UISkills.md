# UISkills.md — Lizard Colony UIデザインシステム

- 版: 1.0（2026-07-11）
- 目的: **Claude CodeがUIに触れる前に必ず読む単一の参照ファイル。** ここに書かれたトークン・コンポーネント仕様・モーション規則・アクセシビリティ規則に**すべてのUI実装を従わせる**。ここに無い独自スタイルを散発的に足さない。

## 0. デザイン言語「Neo-Terrarium（ネオテラリウム）」

> **魂はレトロ。額縁はモダン。**

このゲームは「飼育ケース（テラリウム）を覗く」体験が原点。ドットの生き物・琥珀色の土・素朴な温かさが**魂**であり、これは絶対に失わない。近代化するのは生き物ではなく、その**周囲の枠（パネル・ボタン・遷移・フィードバック）**。

### 5つの柱（全UI実装の判断基準）

1. **魂を残し、皮を磨く** — ドット生物・大地のフィールド・琥珀パレットは維持。モダン化は"額縁"に限定。
2. **平常は静か、ピークは大胆** — 待機画面は可読で落ち着く（レトロ世代の安心）。ボス・巣解放・惑星移動・孵化などのピークは映画的に沸かせる（若年層の高揚）。**この落差が戦略**。
3. **すべてにジュースを** — タップは弾み、数字は回り、報酬は弾ける。ばね（spring）ベースの微反応で"生きている"手触りを出す。ただし常時多用ではなく、行動に対する即時の1発で。
4. **デスクトップ最優先** — PCブラウザ前提。マウス操作（ホバー状態を積極活用）とキーボード操作を軸に、広い画面を活かした情報設計にする。
5. **迷わせない** — 情報階層を明確に。1画面の主役は1つ。装飾が可読性を殺さない。

### 判断に迷ったら
- 「これは生き物（魂）を汚していないか？」→ 生物・フィールドの改変は原則しない。
- 「これは平常画面を賑やかにしすぎていないか？」→ 賑やかさはピークへ寄せる。
- 「新しいスタイルを場当たりで足していないか？」→ 本ファイルのトークン/コンポーネントに無いなら、まずここへ追記してから使う。
- 「絵文字を使っていないか？」→ **絵文字は全面禁止**。すべてのアイコンは自作SVG/スプライトで用意する（§9）。

## 2. タイポグラフィ

**モダンとレトロの二刀流**でフォントを使い分ける（Neo-Terrariumの体現）。

| 役割 | 方針 | 推奨（日本語対応・無償） |
|---|---|---|
| UI本文・データ | 現代的で可読なゴシック | Zen Kaku Gothic New / M PLUS 1p |
| 見出し・親しみ | 丸みのある親近感 | M PLUS Rounded 1c |
| **レトロ差し色** | ドット/スタンプ的な懐かしさを**限定使用** | DotGothic16（STAGE名・実績・称号・"BOSS"等の"判子"的ラベルのみ） |
| 数値カウンター | **等幅数字（tabular-nums）必須** | 上記＋`font-variant-numeric: tabular-nums` |

### 規則
- **レトロフォントは全面に使わない**。可読性を守るため、UI本文は必ずモダンゴシック。ドットフォントは"懐かしさのスパイス"として名詞ラベルに点在させるだけ。
- 大きな数値（Gold・トカゲ数等）は等幅数字で、桁揺れを防ぐ。
- サイズは`clamp()`で流体化（モバイル〜デスクトップで自動調整）。基準: 本文16px / キャプション13px / 見出し20〜28px / ヒーロー数値32〜48px。
- 行間は日本語で1.6前後。字間は見出しのみ僅かに詰める。
- **字サイズの一律倍率(2026-07-17 V5 Phase2)**: 全UIの font-size は `calc(Npx * var(--fs-scale, 1))` 形式とし、`--fs-scale`(tokens.css・現在1.1)の1値で一律調整する。px直書きの font-size を新規に足さない(必ずこの形式で)。canvas内の描画テキスト(ctx.font)は対象外(別途)。

## 3. 空間・角丸・段差

### 3.1 スペーシング（4pxグリッド）
`--space-1:4 / -2:8 / -3:12 / -4:16 / -5:24 / -6:32 / -8:48`。**余白はケチらない**——現代UIの余裕は余白から。パネル内padは最低16px。

### 3.2 角丸
| トークン | 値 | 用途 |
|---|---|---|
| `--radius-sm` | 8px | バッジ・小要素 |
| `--radius-md` | 14px | ボタン・カード |
| `--radius-lg` | 20px | パネル・モーダル |
| `--radius-pill` | 999px | 資源ピル・タブ |

### 3.3 段差（Elevation）— フラットから"層"へ
現状のフラットなパネルを、**やわらかい影＋内側のふちどり光**で層状にする。重すぎるドロップシャドウは禁止（レトロの素朴さを壊す）。

| トークン | 用途 | 参考 |
|---|---|---|
| `--elev-1` | パネル | 影 y2 blur8 rgba(0,0,0,.25) ＋ 内側1pxハイライト |
| `--elev-2` | 浮遊カード・ボタン | 影 y4 blur16 rgba(0,0,0,.30) |
| `--elev-3` | モーダル・ヒーロー | 影 y12 blur40 rgba(0,0,0,.45) |
| `--glass` | オーバーレイ背景 | 半透明ink＋`backdrop-filter: blur(12px)`（対応外はソリッドfallback） |

### 3.4 移行期の中継トークン（Phase 1追記・暫定）

- **レガシー橋渡し**: 旧`style.css`の変数名（`--gold`/`--sub`/`--card`等）は`tokens.css`内でトークンへのエイリアスとして存続させる（JSインラインスタイルの参照を壊さないため）。Phase 2〜4の画面刷新で参照側を直接トークンへ置換し、段階的に撤去する。`--card-hi`のみ`--ink-600`と近接し境界との区別が消えるため現値(#4d3a20)を暫定維持。
- **サーフェス中継**: 既存の繰り返しグラデーション面は`--grad-btn`/`--grad-card`/`--grad-row`等の中継トークンに保存（見た目不変）。Phase 2のコンポーネント刷新で§5仕様のサーフェスへ正式定義し直す。

## 4. モーション

**ばね（spring）を基調に。線形は使わない。** モーションはNeo-Terrariumの"生きている"手触りの核。

### 4.1 デュレーション
| トークン | 値 | 用途 |
|---|---|---|
| `--dur-fast` | 120ms | タップ反応・ホバー |
| `--dur-base` | 200ms | 状態遷移・表示切替 |
| `--dur-slow` | 320ms | パネル/モーダル出入り |
| `--dur-cinematic` | 600–1200ms | ヒーロー演出（ボス・巣解放・惑星移動） |

### 4.2 イージング
| トークン | 曲線 | 用途 |
|---|---|---|
| `--ease-pop` | cubic-bezier(.34,1.56,.64,1) | 弾む出現・タップ（オーバーシュート） |
| `--ease-out` | cubic-bezier(.16,1,.3,1) | 滑らかな遷移 |
| `--ease-in-out` | cubic-bezier(.65,0,.35,1) | 往復・ループ |

### 4.3 定番パターン
- **数値カウントアップ**: 資源増加は即置換せず、短時間で回して着地（`--dur-base`）。桁は等幅。
- **タップ弾み**: 押下scale .96 → 離しscale 1.0を`--ease-pop`で。
- **報酬バースト**: 獲得時に対象へ向けパーティクル数粒＋発光ハロー。
- **入場choreography**: リスト/カードは1要素ずつ40–60ms差でstagger表示。
- **ヒーロー**: 暗転→主役ズームイン→発光→情報ワイプ（§コンポーネントのヒーロー）。

### 4.4 reduced-motion（必須）
`prefers-reduced-motion: reduce`時は、オーバーシュート・パーティクル・カメラ移動を止め、**フェード＋即時値反映**に置換。演出でゲームを止めない。

## 5. コンポーネント仕様

各コンポーネントは「構造 / 状態 / モーション」で定義。既存の同種要素はこれに寄せて統一する。

### 5.1 資源ピル（ヘッダー常設: Gold/トカゲ/ダイヤ/鉱石）
- 構造: `[アイコン][数値(等幅)][増分レート(小)]`をpill形状（`--radius-pill`）に。背景`--ink-700`＋内側ハイライト。
- 状態: 増加時に数値カウントアップ＋アイコンが1回弾む＋琥珀の発光が一瞬。
- モーション: 増加`--ease-pop`。減少は控えめ（色を一瞬`--warn`寄せ）。

### 5.2 アクションボタン — 操作卓モジュール（Brushup V2で確定・案B+立体の手触り）
- **造形**: 真鍮の制御盤モジュール（`--grad-console`・radius 6px・控えめなコーナーねじ2点）。上面ハイライト＋押下で沈む立体（案Aの手触りを借用）で無機質になりすぎない。
- **種別の見分け＝左端インジケータバー＋計器窓（色だけに依存しない構造）**: 主行動=`--life`・ショップ=`--amber`・危機=`--boss`・画面遷移=`--ink-600`（落ち着き）。アイコンは暗い機器窓（inset）に沈める。
- **計器窓（コストバッジ）**: `--lcd-bg/--lcd-text/--lcd-border`＋DotGothic16（レトロの魂を機能表示に）。
- **トグル＝ランプ＋ロッカースイッチ**（一目でスイッチと分かる形状・role=switch）。
- 状態: 通常/ホバー(発光)/押下(沈む+scale.97)/無効50%/長押しプログレスリング（継承）。給餌クランク（§5.10）と同じ「飼育管理装置」の世界観で統一。

### 5.3 カード／パネル
- `--radius-lg`・`--elev-1`・内側1pxハイライト。見出しは小さめ＋区切り。
- 情報過多を避け、1カード1主題。

### 5.4 モーダル
- 背景`--glass`（blur）で後景を沈める。本体`--elev-3`。出入りは`--dur-slow`＋`--ease-out`（下からせり上がり or 中央スケール）。
- 中央スケールインを基本形に。オーバーレイは画面中央へ集約し、後景は`--glass`で沈める。

### 5.5 トースト／通知
- 画面上端or下端に非侵襲で。`--dur-slow`でスライドイン、数秒で自動退場。
- 種別色: 成功`--life` / 危機`--boss` / 情報`--info` / 報酬`--amber`。アイコン併用。

### 5.6 タブバー（設備の通常/防衛、図鑑の惑星別 等）
- pill型セグメント。選択タブは塗り＋僅かな浮き。切替は下線 or 背景がスライド移動（`--ease-out`）。

### 5.7 通知バッジ（惑星マップ/タブ）
- 小円に数 or ドット。種別色。出現時に1回パルス。**常時点滅させない**（不安を煽らない）。

### 5.9 テラリウムのガラス面（メイン画面の額縁・Phase 3追記）
- 中央フィールドを「飼育ケースのガラス越しに覗く」額縁として縁取る。**中の生物・大地の描画(Canvas)には一切干渉しない**(pointer-events: none のCSSオーバーレイ)。
- 構成: 内側1pxのふちどり光＋上端ハイライト＋ごく淡いヴィネット＋最小限の斜め映り込み。
- 強度は2トークンで一元制御: `--terra-glass`(ふちどり光・ヴィネットの総量 0〜1) / `--terra-sheen`(映り込み 0〜1)。初期値は弱め(未決定2)、ディレクター確認で調整。

### 5.10 給餌クランク（v2.1集約 → V5.2 §2 引き算UX改訂）
- 構造: `[大クランク][レート(タップ循環)][オート(後光)][安全装置(後光)]`のコンパクトな塊。**囲み枠・内蔵ランプ・余分な文字は撤廃**し、状態は「ボタン全体の後光」で示す（引き算のUX）。在庫はトップバー＋右パネルに表示（盤面には出さない）。
- **後光による状態表示（V5.2・アンカー改訂）**: **オートON＝ボタン全体が緑の後光**（直感アンカー「緑＝オート」を、内蔵ランプでなく全体発光で表現）。**安全装置ON＝ボタン全体が琥珀の後光**（緑と混同させない）。枠なし・ランプなし。CSSは `#feeder-dial#feeder-dial .fd-sw.fd-glow`（詳細度2,2,0）で全スキンの `.fd-sw` 背景（1,2,0）に順序非依存で勝ち、枠を確実に消す。
- **操作**: タップ=1掴み / 長押し=連続給餌（＝オート高と同速=CFG.dialRates[2]） / **レート=ボタン全体タップで 低→中→高 を循環**（狭い位置クリックを強いない・広い当たり） / オート=現レートで自動。
- **安全装置トグル**: オートと同サイズ。ON=自動停止（琥珀後光）/ OFF=Gold換算補充。**OFF＋オート中に在庫<`CFG.cricketLowWarn`で赤の警告ランプが点滅**（在庫僅少の予告・reduced-motionで点滅停止）。
- **ドラッグ移動**: 群の左上グリップ（点3つ）で、ボタン群を1つの塊として移動できる。位置は `localStorage.feederPos` に保存（次回復元・親#center内にクランプ）。
- モーション: オート回転の1周秒数はレートに同期(CFG.dialSpinSec・高=勢いよく)。オート中タップはばね回転で応える。reduced-motionで回転・点滅停止（機能維持）。
- 配置: 飼育槽右下（既定）。標的はクランク64px級・レート/トグルも44px級。

### 5.8 ヒーローオーバーレイ（ピークの器）
- 全画面 or 大面積。暗転(`--glass`)→主役登場→発光→情報ワイプ→退場。`--dur-cinematic`。
- スキップ可（タップで即終了）。reduced-motion時は簡易フェード。
- 使用先は§6の"大胆な瞬間"に限定。乱用しない。

## 6. 大胆な瞬間（ヒーロー演出カタログ）

**若年層向けの"沸き"はここへ集中投下する。** 平常面には持ち込まない。

### 濃さの原則（Phase 5追記・ディレクター指示）
- ヒーローは大胆でよいが、**1〜2秒で終わる／必ずスキップできる**。
- **頻発するものは軽く・稀なものは重く**（濃淡を意図的に）: 巣ノード解放=中庸（大げさすぎない・でも気づく）／ロケット・伝説誕生など"一生に数回"級=作り込む。
- 演出はオーバーレイ層に閉じ込め、終わったら完全に消える（平常画面に常時光る・常時動く残り香を持ち込まない）。

| 瞬間 | 演出方針 |
|---|---|
| ボス襲来・撃破 | 暗転→ボス降臨カットイン→撃破スロー→報酬噴出（V2演出をヒーロー品質へ底上げ） |

## 8. 推奨ファイル構成（ui.js分割）

現状の巨大`ui.js`は、責務混在で一括置換事故の温床（V4.1で openHQ/openAllies 消失の実例あり）。**UI刷新を機に責務単位へ分割**する。分割は挙動を変えない純リファクタとして先行実施（Sprint Phase 0）。

推奨モジュール（実名は既存規約に合わせる）:
- `ui/tokens`（本ファイルのトークン定義の実体）
- `ui/components/*`（button / pill / card / modal / toast / tabbar / badge）
- `ui/screens/*`（main / nest / hq / planetMap / equipment / breeding / dex）
- `ui/hero/*`（boss / nestReveal / meteorite / warp / rocket）
- `ui/motion`（カウントアップ・stagger・パーティクルの共通ヘルパ）

原則: **1ファイル1責務。関数のエントリポイント（openXxx等）は各screenモジュールに集約し、跨いだ一括置換をしなくて済む構造**にする。

## 9. アイコン方針（絵文字全面禁止）

- **絵文字は一切使わない。** UI・ラベル・トースト・ヒーロー演出・資源表示・通知バッジを含め、本文中の装飾記号としての絵文字（ 等）を全廃する。
- すべてのアイコンは**自作のSVGまたはスプライト**で用意し、統一されたアイコン言語（線幅・角丸・塗り/線のルール）に従う。
- 資源・鉱石・惑星・ボス・味方・設備など、これまで絵文字で仮表現していた箇所は、対応するSVGアイコンへ差し替える。
- アイコンは`currentColor`または色トークンで着色し、テーマ変更（惑星アクセント等）に追従できるようにする。
- レトロの香りはドットフォント（§2）とドット風SVGで出す。絵文字には頼らない。

### 実装（SVG化スプリントで確定）
- スプライトは `js/ui/icons.js` の `ICONS`（24x24グリッド・線幅2・丸端・currentColor）。`Icon.svg(id)` でインライン`<use>`参照。
- CSSは `.icon`（1.1em角・ベースライン-0.18em）。色は親のcolor＝トークンに追従。
- 例外として残す純テキスト記号: `→ ← ⇔ ▸ ★ ☆ ✦ ×`（タイポグラフィであり絵文字ではない。等幅・単色でレンダリングされる）。


## §11 遺伝子ルーレット(V5・roulette.md準拠)

- 設置=左メニュー下部 `#roulette-card` > `#roulette-wrap` > `#roulette-canvas`(専用Canvas・魂のメインCanvasとは別)。
- 描画は表現層(js/ui/screens/roulette.js)がルール層(Roulette)のstateを毎フレーム描くだけ。数値/確率はルール層。
- **レインボー演出**: レインボー帯は七色の淡いグロー(時間で色相回転・当たり位置の明示)。着弾時 `BallEnteredRainbow` イベントで七色バースト+リング(~0.9s減衰)。新種誕生時は枠に `roul-pop` の一瞬の発光。
- モーション: `roul-pop` = ルーレット枠が0.4sで一度だけ発光する当たり演出(prefers-reduced-motionで停止)。
- 色は生命緑/七色HSL。reduced-motionでバースト等を抑制、結果(卵)は保証。
