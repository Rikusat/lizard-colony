## 0. 設計原則 — 「登場の驚き × 有能性のギャップ」

**一目「なんだそれは（笑）」と驚かせ、動くと「有能すぎる」と二度驚かせる。** ギャップが記憶に残る。

- **敵ボス**: その惑星の文明が「失ったもの／歪んだもの／外から来たもの」の化身。crank.md の世界観と地続き。姿は奇抜でも、脅威は本物。
- **味方**: 見た目は間の抜けた/意外な生き物なのに、専門技能で圧倒的に頼れる。**"ギャップ萌え"＝弱そうなのに超有能**。
- **命名**: 種の特徴＋文明の役割を1語に凝縮（カタカナ＋漢字の二段でロゴ映え）。ポップに言いやすく、しかし由来に意味。
- **魂・セーブ不変の原則**（実装時）: 敵/味方はゲームロジック層。導入は破壊的変更＝Ric承認必須。本書は**姿・名・性格・機構フレーバーの提案のみ**。

## 1. 全10惑星 敵ボス × 味方（提案）

### ID1 アリド（始まりの地・乾燥）— 素朴な起点
- **敵ボス**: **「ハリボテ竜」ドロヌマ・ワーム** — 干上がった大地から現れる砂まみれの巨大ミミズ。見た目は間抜けな土管のよう。だが**地中を高速潜航し、足元から突き上げる**初見殺し。始まりの地の「大地そのものの試練」。
- **味方**: **「掘るしか能がない」スナホリ・アルマジロ部隊** — 丸まってゴロゴロ転がるだけの珍生物。実は**一瞬で塹壕を掘り、ベビーを地中シェルターへ退避させる**防御の要（掘削＝始まりの地の生存術）。
- ギャップ: 鈍そうな土管ワーム→神出鬼没 / 転がるだけのアルマジロ→最速の土木工兵。

### ID2 ネオヴェルデ（摩天楼スラム）【Ric種】
- **敵ボス**: **「スマートグラスの」サイバー・スコルピオ** — 高級スマートグラスをかけた気取ったサソリ。**尾の毒針がレーザーポインタ**、AR照準でトカゲを一体ずつロックオン。格差の"上"側の傲慢の化身。ガラス越しに増える死にセグメントのネオンと呼応。
- **味方**: **「電脳」ファルコン（隼）** — スラム育ちのストリート・ハッカー隼。ネオンサインをハックして**敵の照準をジャミング**、格差の"下"から反撃。羽に廃基板を纏う。
- ギャップ: 気取りサソリの本気の火力 / みすぼらしい隼が電子戦の名手。

### ID3 シルヴァ（森林・時計職人）— 木のからくり
- **敵ボス**: **「狂った定刻」クロノ・マンティス（時計蟷螂）** — 全身が木製歯車のカマキリ。**「時を止める」錯覚（テンポの緩急）で攻撃予兆を読ませない**。壊れたからくり時計が意志を持った姿＝職人文明の影。
- **味方**: **「三時のおやつは死守」ゼンマイ・ヤマネ部隊** — 背にゼンマイを差した眠そうなヤマネ。巻くと**規則正しい拍で連射する木製ボウガン隊**に豹変（等時性＝時計文明の技）。
- ギャップ: 優雅な時計→予兆不能の殺気 / 寝ぼけヤマネ→正確無比の斉射。

### ID4 パルス（古代古墳）— 悼み・王墓
- **敵ボス**: **「盗掘者への呪い」ハニワ・ゴーレム／墳王（フンオウ）** — 埴輪が積み上がって起きた土偶の巨人。うつろな目で静かに迫り、**倒すたびに次の埴輪が継ぐ**（悼みは終わらない）。玄室の金を守る番人。
- **味方**: **「燐火を連れた」トムライ・ホタルジャコ（弔い蛍雀）** — 燐火をまとう地味な小鳥。**緑の鬼火で敵をまとわりつかせ足止め**し、負傷トカゲの魂を"仮に"繋ぎ止める（＝回復猶予）。crank.md の緑の燐火と直結。
- ギャップ: 土人形→無限に継ぐ不死性 / 弔いの小鳥→戦場の生命線。

### ID5 イグニス（火山・溶鉱炉）— 鍛冶
- **敵ボス**: **「不良品の逆襲」スラグ・ヒドラ（鉱滓の多頭竜）** — 鋳造に失敗した溶鉄スラグが固まった多頭の塊。**首を落としても炉熱で溶けて再生**（＝溶鉱炉の負の産物）。御神体を鍛えた文明の「失敗作」の化身。
- **味方**: **「金床頭」カジ・モグラ（鍛冶土竜）** — 頭が金床の不格好なモグラ。**その場で味方の牙・爪を打ち直して攻撃力を鍛え上げる**移動鍛冶（＝溶鉱炉文明の職能）。真鍮クランクの祖形を打った民の末裔。
- ギャップ: 溶けた塊→不死の再生 / 金床モグラ→軍全体の強化バフ源。

### ID6 ユンガ（祭祀の密林）【Ric種】
- **敵ボス**: **「髑髏の首飾りの」ドクロ・アナコンダ／贄蛇（ニエヘビ）** — トカゲの髑髏を数珠つなぎに巻いた巨大アナコンダ。**呑み込んだ髑髏の数だけ体力が上がる**（供物＝食料神への冒涜者）。祭祀文明の禁忌の化身。
- **味方**: **「小さき射手」クロスボウ・マングース部隊** — 弩（クロスボウ）を構えた小柄なマングース兵団。**蛇の天敵として一斉射で怯ませ、群れ戦術で大蛇を仕留める**。御神体を守る神使の眷属。
- ギャップ: 数珠蛇の理不尽な体力 / 小マングースが大蛇を制する連携。

### ID7 メアリス（水中都市）【Ric種】
- **敵ボス**: **「溶土化した」マグマ・シャーク／熔鮫（ヨウザメ）** — 海底火山の熱で半分溶けた土（溶岩泥）を纏う巨大鮫。**津波の周期に乗って突進**（静寂の都を脅かす自然の猛威）。引き算の静寂を破る"力み"の象徴。
- **味方**: **「錨を巻いた」インテリ・オクトパス／碩学蛸（セキガクダコ）** — 眼鏡をかけ錨を巻きつけた理屈っぽいタコ。**8本の腕で同時に耐圧ハッチを操作し、津波の直撃を防潮壁で受け流す**（水圧制御＝都の知恵）。深海照明の緑と呼応。
- ギャップ: 溶けた鮫の質量攻撃 / 理屈屋タコが都市防衛システムそのもの。

### ID8 グラキス（氷の前線・軍事）— 外部干渉
- **敵ボス**: **「規格外」ヌシ・バガー／親個体（オヤコタイ）** — 既存バガーボスの上位。**"外側"へ抜けようと飼育槽のガラスを内側から叩く**（メタ構図・crank.md §3.4のバガー掃討設定と地続き）。上位存在が代理防衛を敷いた理由の顕現。
- **味方**: **「借り物の銃架」ジャンク・ペンギン・サーボ隊** — 与えられた軍用サーボを不格好に背負ったペンギン。**冷たく正確な自動照準で淡々と一掃**（軍用グレードの無機質さを、とぼけたペンギンが纏うギャップ）。監視柱の赤い光学と同系統。
- ギャップ: ガラスを叩く不気味さ / ずんぐりペンギンが最精密の掃討兵。

### ID9 ヴォルタ（廃原子炉）— 使い捨て
- **敵ボス**: **「暴走した試作炉」メルト・ゴーレム／臨界獣（リンカイジュウ）** — 廃炉パーツの寄せ集めが自我を持った塊。**熱暴走ゲージが溜まると全体攻撃→自ら急速冷却でリセット**（crank.md の熱暴走/瞬間冷却の敵版）。使い捨て文明の"捨てられなかった"怨念。
- **味方**: **「使い捨て上等」ジャンク・ラクーン整備班** — 応急テープだらけのアライグマ整備兵。**壊れても即・別パーツで直して戦線復帰**（ちゃちいのにキビキビ＝クランクの手触りの味方版）。黄テープの意匠を共有。
- ギャップ: 寄せ集めの塊→周期的全滅級 / ボロ整備班→不屈の再稼働力。

### ID10 オリジン（古代遺跡・末路）— 原点回帰
- **敵ボス**: **「静寂を破る者」レリック・スフィンクス／守墓像（シュボゾウ）** — 渾天儀の遺構に宿った石の守護像。**"問い"（謎かけ）を出し、無視すると重い一撃**（発展を極めた文明の最後の理性）。倒すのでなく"応える"含みを持たせられる。
- **味方**: **「全てを憶えている」記録係アノール／文机トカゲ（フヅクエ）** — 石板を抱えた学者肌の小トカゲ。**過去全惑星の敵の弱点を"閲覧"して味方に伝える**（＝図鑑/記憶の博物館＝原点回帰の体現）。金の遺物＝全所業の縮図と直結。
- ギャップ: 静かな石像の問答→物理の重み / 内気な記録係が全戦術情報の要。
