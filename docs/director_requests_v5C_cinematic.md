## 1. 技術制約(本作の規律を継承)

- 素の HTML/CSS/JS・ビルドなし・**Canvas 2D のみ**。外部ライブラリ・外部アセット(画像/動画ファイル)禁止。
  描画はすべてコード内で完結させる(パスデータの埋め込みは可)。
- 決定論: 乱数を使わず `fmix32` 等のハッシュ+時刻で表現する(スクショ比較・QAの再現性)。
- `prefers-reduced-motion` 対応: アニメーションを止め、最終画(タイトル)を静止表示する。
- **スキップ可能**: クリック/タップ/キー入力でいつでも中断できる。中断は即時、確認を挟まない。
- 再生済みフラグはセーブに単調追加(既存セーブは未再生扱い)。設定から再視聴できてよい。
- 尺は **10秒前後**(±2秒可)。長くしない。
- 負荷: 再生中のみ描画。ゲーム本編の描画ループ・状態には非接触。
- 全パラメータ(尺・各カットの長さ・色・スキップ可否・自動再生)はCFG化。

## 3. 表現の方針

### 3-1 禁止事項(ディレクター試作4版の失敗記録・厳守)

ディレクターが試作を4版作り、Ricの判定は **v2=20点 / v3=1点** だった。原因は以下で、同じ轍を踏まないこと。

1. **主役の不在**: トカゲを小さなシルエットで背景に置くと、誰の物語か分からない。
   → **トカゲを画の主役に据える**。大きく、はっきりと。
2. **3Dに見える陰影**: 物体に放射グラデーション・光彩ぼかし(shadowBlur)・リムライトを乗せると立体になり、
   2Dアニメに見えない。→ **物体への陰影グラデーションは禁止**。面は塗りで割る。
3. **線画表現**: 虹を細い弧の重ね、環や惑星を輪郭線(stroke)で描くと、シネマティックでなく**図解**になり、
   クオリティが激しく下がる。→ **線で描かない。塗りの塊で構成する**。strokeは原則使わない。

### 3-2 目標とする質

- 2Dアニメーション作品のタイトルシーケンスとして成立すること。ポリゴンの粗さは許容するが、**安っぽさは不可**。
- 奥行きは**値(明度)の差と重なり**で作る。手前ほど暗い、奥ほど明るい。
- 1カット1色調。カットごとに限定パレットを決め、混ぜない。
- 動きは大きく少なく。細かい効果を散らすより、1カットに1つの明快な動きを置く。
- ゲーム内の描画(魂)と**別の絵で構わない**(Ric裁定)。ムービー専用の描き方をしてよい。

### 3-3 参考資料

- 参照映像: Ricが別途共有(2Dゲーム風の質感・暗部主体・低彩度・冷たい紺に暖かい琥珀の光源・
  明暗のアークがある)。リポジトリに置く場合は `docs/design/ref/` へ。
- ディレクター試作 v1〜v4(`docs/design/opening-poc/` に配置予定): **採用案ではない**。
  失敗の記録として、何が駄目だったかの現物確認に使うこと。良い部分(構成・語り・色言語)は流用してよい。

## 4. 進め方(承認ゲート厳守)

過去アーク(HOLO COMMAND・四重スリット意匠)で有効だった型を用いる。

1. **基準カット3案比較**: 同一の1カット(推奨=カット2「ロケット脱出」または カット1「崩壊」)を、
   **絵作りの流儀が異なる3案**で作る。案ごとに何が違うかを一言で説明すること。
   例: (a)塗りの塊主体 (b)粗いポリゴン主体 (c)アニメのセル塗り主体 — 案の立て方はCCの設計。
2. `?tune=1#opening` の比較ビューアで3案を並べ、**Ricが目で選ぶ**。
3. 選定案で**全編を制作** → Ric判定 → 必要なら調整 → デプロイ承認。
4. 各段階でスクショ+確認URLを併記。静止画で伝わらない要素は連番(位相をずらした2〜3枚)を添える。

## 5. 安全境界

- ゲーム本編のロジック・セーブ・経済・確率・純血・魂に非接触(再生済みフラグの単調追加のみ)。
- 既存のQAゲートに影響を与えないこと。QA3層 + boot console0 を維持。
- 再生機構は独立モジュールとし、本編描画ループに条件分岐を増やさない設計を優先する。
- デプロイはRic判定後。同乗デプロイ禁止規律を適用。

---

## 6. 判定基準(Ricの判定観点)

1. **世界が伝わるか**: 10秒見て、このゲームの舞台と目的が掴めるか。
2. **主役が居るか**: トカゲの物語として見えるか。
3. **2Dとして成立しているか**: 立体に見えない・図解に見えない・安く見えない。
4. **見たあとゲームを始めたくなるか**(最終的にはこれが全て)。
