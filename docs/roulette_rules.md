# roulette_rules.md — 遺伝子ルーレット 盤面設計憲章（レール・受け皿・惑星別意匠）

- 版: 1.0
- 位置づけ: `roulette.md`（システム憲章＝物理・確率・結果モデル）に対し、本書は**盤面の構造物**——レール、受け皿（景品穴・虹穴の受け）、釘、台のデザイン——を定める。**惑星ごとの意匠差し替え**もここで管理する。
- 関連: `roulette.md`（物理・3結果モデル）、`crank.md`（惑星ごとの機構表現の思想）、`UISkills.md`（UI仕様）、fable群。

## 0. 原則 — 骨格は不変、意匠は惑星ごと

`crank.md` でクランクに適用した思想を、ルーレット台にも適用する。

- **物理骨格・確率は全惑星で不変**：重力・反発・固定dt・3結果モデル（景品穴＝卵／虹穴＝大当たり／それ以外＝ハズレ）・大当たり0.5%・卵獲得率。**惑星によって当たりやすさが変わってはならない**（公平性）。
- **変わるのは意匠と配置の"見た目"**：レールの形状、釘の配置パターン、受け皿の造形、台のデザイン、色。惑星の世界観を語る。
- **判定基準**：「別の惑星の台だと一目で分かるが、遊び方と当たりやすさは同じ」。

> ※釘やレールの**配置**を変えると確率が動くため、意匠変更時は必ずモンテカルロで3率（卵獲得・大当たり・ハズレ）を再測し、目標帯（大当たり0.5%・卵獲得1/15〜1/20）に収まるよう穴幅等で再調整する（§4）。

## 1. レール（発射→落下導入）

- **役割**: 射出された球を、まずレールに沿って落下させ、フリーフォール区間へ導く（`roulette.md` §1.3-1）。
- **設計指針**:
  - レール終端＝**解放点**。ここから先は自由落下＋釘で、軌道に縛られない。
  - レールは「発射の勢いを受け止めて、盤面へ送り出す」導入部。長すぎると自由落下の面白さが減り、短すぎると発射が唐突になる。長さ・曲率はCFG。
  - レールは球が**沿って走る**ことが視覚的に分かる形状に（溝・ガイド・軌条など、惑星の意匠で表現）。
- **惑星別の変化例**: 真鍮の管／ネオンの光条／石の溝／木の樋／導管／軍用のレール／水路 など（各惑星の素材・世界観に合わせる）。

## 2. 受け皿（景品穴・虹穴の受け）

- **役割**: 落下した球が**入賞したことを視覚的に確定させる**装置。球が「コトンと収まる」場所。
- **構成**（`roulette.md` §1.4 の3結果に対応）:
  - **虹穴の受け皿**：中央・極細。大当たり（未所持の新種）。入った瞬間が最大の見せ場。
  - **景品穴の受け皿**：虹穴を左右から挟む帯。卵を獲得。
  - **ハズレ**：どちらの受けにも入らず、**球は流れて消える**（受け皿を持たない＝落ちて消滅）。
- **満杯時の景品穴クローズ**（②a）: **卵スロットが満杯のとき景品穴は物理的に閉じる**。閉じた穴には金属の蓋（×印）が描かれ、景品帯へ落ちた球は入賞せず**ハズレ扱い**（`Roulette.canAcceptEgg()` が false → `_resolveLanding` で `win=false`）。満杯が**盤面で一目で分かる**こと。**虹穴（大当たり）は常に開いており満杯でも必ず入る**（レア＝未所持新種の保護。`spawnRouletteEgg` で満杯上限を虹のみバイパス）。
- **設計指針**:
  - **入賞の瞬間が「収まった」と分かること**。素通りでなく、受け皿に球が入る／留まる動きで、獲得を体感させる。
  - **虹穴は極細で、ニアミスが頻発すること**が緊張の源泉（最後の釘で弾かれて脇の景品穴へ落ちる「惜しい!」）。虹穴の直上には振り分け釘を置き、入りにくさと期待を両立させる。
  - 受け皿は**常に見えている**（結果が出る場所が分かる＝期待の対象になる）。満杯時のみ景品穴の受け皿が蓋で塞がれ、虹穴の受け皿は開いたまま。
- **惑星別の変化例**: 真鍮の受け皿／ネオンのスロット／石の窪み／木の升／坩堝／耐圧ハッチ／祭壇の器 など。

## 3. 釘（偶然性の装置）

- **役割**: 落下中の球を不規則に跳ねさせ、**予測不能さ＝緊張**を生む（`roulette.md` §1.3-3）。減速の焦らしを撤回した v3 では、**釘の跳ねが緊張の主役**。
- **設計指針**:
  - **球が主役、釘は舞台装置**。低コントラスト・控えめな造形で、落下する球の軌跡を追う邪魔をしない（UISkills「平常は静か」）。
  - 千鳥配置を基本とし、虹穴の上には振り分け釘を置く。
  - 配置を変えると確率が動く（§4を必ず実施）。
- **惑星別の変化例**: 真鍮のピン／ネオンの発光ノード／石の突起／木のダボ／溶鉄の滴／軍用のスパイク／珊瑚 など。

## 4. 惑星別意匠の変更手順（必須プロセス）

惑星ごとに釘・レール・受け皿・台のデザインを変える際は、**必ずこの順で行う**。

1. **意匠を設計**：その惑星の世界観（`crank.md` §3の惑星設定・クランク機構）と揃える。素材・色・形状を決める。
2. **配置を実装**：レール形状・釘配置・受け皿位置を変更。
3. **【必須】確率の再測定**：モンテカルロで3率（卵獲得率・大当たり率・ハズレ率）を実測する。
4. **【必須】目標帯へ再調整**：大当たり **0.5%（1/200）**、卵獲得 **1/15〜1/20** に収まるよう、穴幅（虹穴・景品穴）等で調整する。**配置を変えたまま確率がズレた状態で確定しない**。
5. **記録**：惑星ごとの確定パラメータと実測3率を本ファイル §5 に記録する。

> **公平性の原則**: どの惑星でも当たりやすさは同じ。意匠が違っても、確率は全惑星で揃える。

## 6. 制約（全惑星共通）

- 物理骨格（重力・反発・固定dt・決定論・単一シード窓口）は不変。意匠変更で決定論を壊さない。
- 魂（トカゲ・大地・飼育槽の描画）は不変。
- 全パラメータはCFG化（意匠ごとの配置・穴幅も含む）。
- reduced-motion時は演出を簡略化しつつ結果は保証。
- 意匠変更は1惑星＝1コミット。変更後に必ずモンテカルロ3率とスクショを提示し、Ricが手触りを判定する。
