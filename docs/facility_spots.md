# facility_spots.md — 設備の「トカゲの居場所（スポット）」レジストリ

- 版: 0.1（2026-07-20・Phase 8.5 で新設）
- 位置づけ: 各設備が持つ**トカゲの居場所（スポット）**の座標・向き・想定姿勢を記録する（`GameExpansion_V5.md §8.5`）。
  **モーションは未実装。** ここは「形状の設計時点で確保したスポット」の台帳であり、将来モーション実装時に参照する。
- 座標系: 飼育槽バッファ 1280×720。設備の定位置は `FAC_POS`（render.js）。スポットは設備がその tier のとき有効。
- 向き: `→`(right, angle 0) / `←`(left, angle π)。姿勢=将来の motion 名の目安。
- 実装原則: スポットは**その設備の形状の中に物理的に確保**する（縁・ランプ下の空間・入口・浅瀬 等）。tier で規模が育つと、スポットも設備スケールに追従して移動しうる（座標は代表 tier のもの＋算出式）。

## スポット一覧（設備ごと）

各設備は「トカゲがそこで何をするか（action）」を持ち、その居場所を形状に確保する。

### 水場（water・P.water=(230,610)）
- **action**: 水を飲む（tier1-3）／水浴び・水遊び（tier4 大湖）。
- **spot（飲む・tier1-3）**: 池の**手前の縁**。座標 ≈ (P.water.x, P.water.y + ry\*0.85)（ry=waterTierInfo(lv).ry）。向き `→/←`（水に頭を向ける）。姿勢=「drink」（頭を下げて水面へ）。
- **spot（水浴び・tier4 大湖）**: **浅瀬**。代表座標 ≈ (300, 600)（岸に近い明るい浅瀬）。向き=水（左下）へ。姿勢=「wade/splash」（浅瀬に半身を浸す・尾で水を跳ねる）。浅瀬帯は岸辺の弧に沿って ~ (250〜360, 585〜620)。
- 形状の確保: tier1-3=手前の縁を平らに開ける。tier4=岸に接する**浅瀬の帯**を明るく確保（陸から歩いて入れる）。

### 保温設備（heat・P.light=(1010,322)）※§8.8 UFO転送ビーム / §8.12 で旧・展望台位置(右=ボス側)へ移動
- **action**: 暖をとってくつろぐ（バスキング）。**tier3/4 は群れが入れる広い光面**。
- **spot（バスキング・tier1-2）**: **ランプ直下/温室内の温床**。座標 ≈ (P.light.x, P.light.y + 44)。向き=任意（光源=上）。姿勢=「bask」。
- **spot（バスキング面・tier3-4 空中ライト）**: **地上に降りるビームの広い光円**（= heatTierInfo(lv).beamR 半径の面。群れが集まれる）。中心 ≈ (P.light.x, P.light.y)。姿勢=「bask」（面のどこでも伏せられる）。
- 形状の確保: tier1-2=温床の平地。tier3-4=空中エミッターからのビーム着地点に**半径 beamR の明るい光面**を確保（放射グラデ）。tier4 は光柱にシルエットが昇る転送演出（装飾・実個体とは別）。

### 展望台（observatory・FAC_POS.observatory=(640,300)）※§8.9 観測施設群 / §8.12 で中央へ配置し巨大化(ランドマーク)
- **action**: 観測する・空を見上げる（群れで集まる）／塔上で見張る。
- **spot（見上げ・群れの面）**: **手前の観測広場（淡い舗装の面）**。中心 ≈ (cx, gy+16)、半径 ≈ (deck幅)×0.66。向き=上（空）。姿勢=「lookup/bask」（面のどこでも見上げられる＝収容力）。
- **spot（見張り・tier3）**: **観測塔の塔上バルコニー**。座標 ≈ (cx + hw×0.72, gy − h×0.92)（手すり付き）。向き=遠く/空。姿勢=「lookout」。※高所のため代表は1匹。
- 形状の確保: 施設群の手前に**広い観測広場の面**を開ける（構造物は奥の板張り土台に乗せ、群れは手前の広場に立つ）。塔上に平らなバルコニーを確保。

### ~~餌場~~（撤廃・§8.12）

### ~~繁殖施設~~（撤廃・§8.12）

### すみか（巣穴・FAC_POS.burrow=(185,322)）※§8.12 で旧・保温位置(左=ボス登場側の反対)へ移動＋給餌・繁殖効果を統合（コロニーの中核設備）
- **action**: 出入りする・入口で日向ぼっこ。
- **spot（出入り/日向ぼっこ）**: **入口の手前**。座標 ≈ (480, 668 - 4)（穴の手前の縁）。向き=穴（上）or 外（下）。姿勢=「enter/emerge」or「bask」。
- 形状の確保: 入口の手前に平らな踏み段を確保（済／要点検）。

### ~~シェルター~~（撤廃・§8.10）
