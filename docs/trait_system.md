## 1. 不変のコンセプト（確定・変更しない）

- **純血設計の上に「個性」を乗せる。** 種は惑星ごとの固有2種のみ（Phase 4）。その上に**横方向の収集軸＝特性**を足す。
- **縦の序列（レア度）を消し、横の収集を足す。** 「皆違って皆良い」。
- **特性はスキン（見た目の個性）であり、戦闘力・生産力を与えない。** 優劣ではなく違い。
  - ※これにより「強い特性を集める作業」ではなく「好きな個性を作る遊び」になる。
- **射幸心が核。** 放置難易度を下げたのは、プレイヤーの熱量を**レア個体を掛け合わせる射幸心**に集中させるため。やり込み率の指標であり、**コミュニティが育つ理由**（一人の達成＝他者に見せたくなる出来事）。
- **レジェンダリーは特性の対象外。** 虹色そのものが最上の個性であり、横並びの外にいる別格。

## 4. 【新規・本幹】合成システム（トランスミュート）

> **位置づけ**：繁殖ガチャ（運）と賢者の石（錬金）の**到達点**。2つの特性を併せ持つ個体を素材に、**上位の特性を錬成する**。
> やり込みの階層を作る：**genesis で種を得る → 繁殖で掛け合わせる（0.09%）／石で固定して2枚持ちを作る → 合成で上位特性 → さらに掛け合わせる**。

### 4.1 基本ルール（案）
- **素材**：指定の2特性を**併せ持つ個体**（＝2枚持ち。0.09%のガチャ、または石固定で作る）。
- **場所**：**本部＝研究施設の「実験用水槽」**（`hq_lab.md`）。
- **触媒**：賢者の石を消費。
- **結果**：レシピに合致すれば、**上位特性**が生まれる（生成先は §4.3）。
- **レシピ**：`A + B → C`。上位特性ほど深い階層（C同士でさらに上位、等）。
- **全パラメータCFG化**（コスト・成功率・レシピ）。

### 4.2 【Ric判断①】素材個体の扱い ★最重要
本作の原則は**「資産は消さず、損失感ゼロ」**。合成で素材個体をどう扱うか：

- **案A：素材個体は消費しない（特性だけを"写し取る"）** — 損失ゼロ。石コストのみが対価。最も原則に忠実。
- **案B：素材の特性が失われる（個体は残るが traits から該当2つが消える）** — 個体は生きる。代償はあるが命は失わない。
- **案C：素材個体を消費する（消滅）** — 錬金術の重みは最大だが、**育てた個体を失う**＝原則に反する。採るなら復元手段が必須。

→ **推奨：案A または 案B。** 「育てた個体が消える」体験は、本作が一貫して避けてきたもの（コオロギ払い戻し・純血化のバックアップ・設備撤廃の全額返金）。

### 4.3 【Ric判断②】合成で生まれる特性の性質
- **案I：既存ロスターの上位tier特性**（例：ネオン＋クロノ → アミダグラ）。ロスター内で完結。
- **案II：合成でしか手に入らない専用特性**（"合成種"）。到達の証＝コミュニティで見せたくなる。
- → **推奨：案II（専用特性）**。合成の価値が明確になり、「持っている＝到達した」の証明になる。ロスターに **合成専用の上位ティア** を数種用意する。

### 4.4 【Ric判断③】レシピの公開度
- **案i：最初から一覧で公開**（迷わない／作業計画が立つ）
- **案ii：秘匿。本部の研究で解放**（発見の喜び／HQ育成の意味づけ）
- **案iii：ヒントのみ提示**（気配だけ見せて説明しない＝crank.mdの作法）
- → **推奨：案ii＋iii**。本部（パソコンデスク群）を育てるとレシピが解読されていく＝**HQ育成の動機**になる。

### 4.5 成立条件（設計制約）
- 合成は**特性のみを扱う**。**種族は絶対に変えない**（純血設計を崩さない）。
- **レジェンダリーは素材にも結果にもならない**。
- 生成された特性も**上限3**・**遺伝はtier基準の p**（合成専用特性は tier5 相当＝3%）に従う。
- **決定論**（単一シード窓口）。結果の事前確定は禁止（成功率がある場合は乱数を単一窓口経由）。
- **セーブ**：traits/fixedTraits の追記・除去に留まるなら bump 不要。レシピ解放状態を保存する場合は additive で（bump要否を実測）。

## 7. 判断の記録（2026-07-23 Ric確定）

1. **§3.2 ロスター**：方向承認（ミミカクシ/ネオン/ハクシ/トライアドの3+1種で基準確立）。**部位と手法を散らす**（顔/四肢/体側/鱗の質感/縁/微光…背の斑紋に偏らない）。rim色=UISkills惑星アクセント流用も承認。命名は全て仮＝Ric最終語感。残り8種を1つずつ実装→スクショ確認。
2. **§4.2 素材個体の扱い → 案B で確定**：同一個体上で `traits:[A,B] → [C]` へ**昇華**（個体・レベル・体色は残る）。理由：案A(写し取り)は2枚持ち1匹からの**無限鋳造**で「持っている＝到達した」の証明価値が石の相場品に堕ちる／案Bは錬金の重みが構造で出る・上限3が自然・量産には2枚持ちの作り直し＝遊びが死なない。
   - **固定印(fixedTraits)付き特性は素材にできない**（石投資の事故消失防止・UIで明示）＝承認。
   - **固定印は個体ごと・子には伝播しない**（実測0/2000・恒久テストで固定）→ 石固定で作った2枚持ちの子は固定印なし＝**そのまま合成素材にできる＝石の道は合成へ到達する**（必須条件を実測で確認済）。
3. **§4.3 → 案II で確定**：合成専用特性（内部tier6相当・遺伝はfloorの3%）。到達の証。
4. **§4.4 → 案ii＋iii で確定**：レシピ秘匿・パソコンデスク群の研究で解読・未解読は「?」カードと気配のみ。
5. **成功率 → 無し（100%確定）で確定**：「運は裏切る（繁殖）、錬金は裏切らない（石）」の一貫性。失敗RNGは入れない。リスクの手触りが要る場合はコスト（石数）の傾斜で。
6. **特性図鑑（コンプ率）**：標本棚（hq_lab）に置く方向（実装時に最終確認）。
7. **S6（旧個体への遡及付与）**：引き続き保留。着手は最後・単独・明示承認後。

### 8.5 解読（確定）
- RESEARCH様式（前提チェーン）で**レシピ解読I〜VI**。デスク群tierが上がるほど深い解読が可能＝本部育成の動機。
- コスト＝研究力＋後半は賢者の石を少量（錬金の知識は石が教える）。
- 未解読＝「?」カード＋**素材2特性のロゴをシルエット表示**（気配のみ・説明しない）。
- データ駆動: `RECIPES = [{a, b, result, order, cost}]`（レシピ追加＝データ追加のみ）。解読状態は既存 `state.research` 枠（additive・bump不要）。

### 8.6 【要検討・実装時に提示】賢者の石の経済
吸い口が4つ（①genesis 2-6個 ②固定化 6-14個 ③合成触媒(未定) ④解読の一部）。合成実装時に、
**入手ペース（能動/放置・個/時）／各吸い口の想定消費／「創世→2枚持ち→合成」1周の総石数／枯渇か余剰かの見立て**を数字でまとめてRicに提示→CFG最終調整。
