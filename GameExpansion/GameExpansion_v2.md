## 設計哲学（最重要・全タスク共通の判断基準）

> **ルールを増やさない。体験を増やす。**

このゲームは完成している。プレイヤーに新しい暗記事項を課す拡張は**却下**。採用するのは「既存の仕組みの再結合・再スキンで、見た目と結末が新しくなる」拡張のみ。迷ったら次の順で判断する:

```
既存システムの再利用 > 演出の追加 > 数値の追加 > 新ルールの追加（最終手段・原則禁止）
```

具体的には——新ボスは既存の襲撃フローに乗せる／新設備は既存の「設備」導線に足す／終盤コンテンツは既存の通貨・撃退数・図鑑を集計するだけ、を徹底する。プレイヤーが覚える操作は増やさない。

## ② 新ボス（ランク40以降、既存襲撃フローに追加）

**方針**: 全て「フィールド端から目標へ向かい、迎撃で削る」という既存構造に乗せる。違いは**狙う対象・攻撃の見た目・弱点（＝プレイヤーの対策）**だけ。弱点は必ず**既存の設備か味方（⑩）に紐づけ**、対策が「新しい遊び」になるよう設計する。

各ボスは①専用AI ②専用攻撃 ③専用演出 ④弱点 ⑤攻略法 を持つ。

### B-1 猛禽類・鷹（Hawk）— 空の狙撃者

| 項目 | 仕様 |
|---|---|
| AI | 上空を旋回（画面上部を横断）→ 急降下ポイントを1.5秒予告（地面に影＋赤リング）→ ゴールデン系個体を最優先で1匹さらいに来る |
| 攻撃 | 急降下1回でゴールデン個体を空へ連れ去ろうとする。掴む前に迎撃HPを削れば阻止。成功されると該当個体が一定時間フィールドから消える（死なない・時間経過で戻る） |
| 演出 | 旋回中の鳴き声SE、急降下の風切り音、影マーカー、掴み失敗時の羽根パーティクル |
| 弱点 | **ワシ（味方）** が居ると空中で迎撃し急降下を妨害。**保温ライト** の光でゴールデンが目立つため、ライト密集地は狙われやすい（リスクとして提示） |
| 攻略 | ワシを配備 or 急降下予告リング内をタップ連打で追い払う。ゴールデンを一時的にシェルターへ退避させる操作を許可 |

### B-2 巨大カラス（Giant Crow）— 卵泥棒

| 項目 | 仕様 |
|---|---|
| AI | 巣・卵スロットへ直行。到達すると孵化中の卵を1つ奪って逃走する |
| 攻撃 | 直接ダメージはない。**資産（卵）を奪う**タイプ。逃走中に迎撃で撃墜すれば卵を落として奪還できる |
| 演出 | 卵を咥える瞬間のズーム、逃走の羽ばたき、撃墜時に卵がバウンドして戻る |
| 弱点 | **巣箱（設備）** が卵を守る（奪取猶予を延長）。**フェンス** が侵入経路を制限し到達を遅らせる |
| 攻略 | 巣箱を建てる／逃走ルート上をタップして撃墜／襲撃前に卵を孵化完了させておく（時間管理の駆け引き） |

### B-3 大型トカゲ（Rival Monitor）— 縄張り争い

| 項目 | 仕様 |
|---|---|
| AI | フィールド中央へ堂々と侵入し居座る。周囲のアダルトを威嚇して**探餌・繁殖行動を一時停止**させる（生産低下＝経済への圧） |
| 攻撃 | 高HP・高防御のタンク。迎撃に時間がかかる。居座り時間が長いほど生産ロスが増える |
| 演出 | 地響き登場、睨み合いのにらみエフェクト、撃退時の咆哮 |
| 弱点 | **数の暴力**（アダルト多数で袋叩き）。**展望岩（設備）** で早期予告が出るため準備が間に合う |
| 攻略 | アダルト頭数を確保／展望岩で早期対応／カメ（味方）で足止めしてから集中攻撃 |

### B-4 サソリ（Scorpion）— 毒の使い手

| 項目 | 仕様 |
|---|---|
| AI | 低速で巣へ接近。迎撃トカゲに**毒（継続ダメージ状態）**を付与し、迎撃効率を下げる |
| 攻撃 | 毒スタック: 迎撃トカゲの与ダメージが時間とともに低下。放置すると迎撃が瓦解 |
| 演出 | 尾の一撃フラッシュ、毒を受けた個体が紫に明滅、水浴びで毒が抜ける演出 |
| 弱点 | **水場** に触れた迎撃個体は毒が解除される（既存設備の再利用！）。**研究所（設備）** の解析で毒耐性バフ |
| 攻略 | 水場付近で戦う立ち回り／研究所バフ／サソリ本体を早期集中撃破して毒源を断つ |

### B-5 巨大クモ（Giant Spider）— 拘束者

| 項目 | 仕様 |
|---|---|
| AI | 侵入経路に**巣（ウェブ）を張る**。ウェブに触れたトカゲは移動速度が低下し、迎撃到達が遅れる |
| 攻撃 | 直接火力は低いが、フィールドの機動を奪う「地形改変」型 |
| 演出 | ウェブが張られるアニメ、絡めとられた個体のもがき、ウェブ焼却の炎演出（火山ステージと親和） |
| 弱点 | **ヤモリ（味方）** がウェブを切る。**火山ステージの環境** や炎系設備でウェブが焼ける |
| 攻略 | ヤモリ配備／ウェブをタップで除去（連打でほつれる）／機動に頼らず水場やライト周辺の密集で受け止める |

**設計メモ**: 5体それぞれ「奪う／止める／毒／拘束／空」と**脅威の種類が全部違う**。同じ迎撃でも毎回違う対処が要るため、体験が反復しない。弱点が既存設備・味方に紐づくので、プレイヤーは新ルールを覚えず「手持ちの道具で解く」だけ。

**受入条件**: 各ボスが専用の狙い（ゴールデン/卵/生産停止/毒/減速）で登場し、対応する設備・味方があると明確に有利になる。対策不在でも撃退自体は可能（詰みを作らない）。

## ④ UI改善 — 長押し連続実行とモバイルUX

**方針**: 終盤は購入・給餌の回数が爆発する。「押す回数」を減らすのが最大のUX改善。新画面は作らず既存ボタンを賢くする。

1. **長押し連続実行**: コオロギ購入（×10 / ×100）・一括餌やり・繁殖に長押し対応。
   - 押しっぱなしで 0.4秒後から連続実行開始、0.15秒間隔。押し続けるほど間隔が段階的に短縮（最短0.05秒）＝加速オートリピート。
   - 実行中はボタンにゲージ or 実行回数バッジを表示。指を離すと停止。
   - Gold/在庫が尽きたら自動停止＋トースト。
2. **タップ判定拡大**: 全主要ボタンの当たり判定を視覚サイズの1.2倍以上（モバイル最低44px相当）。
3. **数量ステッパー**（任意・低コスト）: 購入ボタンに「押した回数の累計と合計コスト」をリアルタイム表示。
4. **誤爆防止**: 「今すぐ襲来！」など不可逆アクションは長押しの対象外とし、短押し＋確認を維持。
5. **触覚/視覚フィードバック**: 連続実行の1回ごとに軽い明滅＋カウント音（ピッチ上昇で気持ちよさを担保）。

**受入条件**: 購入・給餌・繁殖が長押しで加速連続実行でき、資源枯渇で自動停止する。スマホでの誤タップが体感で減る。

### シナジー（“組み合わせると強い”の発見を作る）

- **保温ライト＋日光反射板＋大型保温器** → バスキング特化。体力回復が跳ね上がり、雪原ステージで真価

## ⑦ 繁殖UI改善 — 二段階選択

**方針**: 大量個体を「系統でまとめて畳む」。全個体フラット表示を廃止。

**画面遷移**

```
[繁殖する] → 第1画面: 系統一覧（種別カード）
                 ↓ 系統を選択
             第2画面: その系統の個体一覧
                 ↓ 2匹選択
             繁殖確定
```

1. **第1画面（系統一覧）**: 系統ごとにカード表示。各カードに **系統名 / 総個体数 / 繁殖可能数 / 代表サムネ / レア度アイコン** を表示。繁殖可能数>0のカードにバッジ。
2. **第2画面（個体一覧）**: 選択系統の個体をグリッド表示。各個体に 名前・成長段階・幸福度・レア度・繁殖可否（クールダウン残）を表示。繁殖可能個体を上位ソート。
3. **選択操作**: 2匹タップで確定。相性/遺伝プレビュー（子のレア度予兆）は遺伝解析室があれば表示。
4. **フィルタ/ソート**: レア度順・幸福度順・繁殖可能のみ、の簡易切替。
5. 空系統・繁殖不可のみの系統はグレー表示で最後尾へ。

**受入条件**: 100匹規模でも系統カードで一覧が畳まれ、系統→個体の二段階で2匹を選んで繁殖できる。各カードに個体数・繁殖可能数が出る。

## ⑧ クイック繁殖

**方針**: 「最善の2匹」を自動選択するワンタップ。終盤の作業感を消す。

1. 繁殖画面上部に **[クイック繁殖]** ボタンを追加。
2. **自動選抜スコア**（初期式・要調整）:
   ```
   個体スコア = レア度重み×3 + 幸福度×1 + 成長段階ボーナス
                （繁殖不可個体はスコア対象外）
   ```
   スコア上位2匹を選択。ただし**同系統ペア優先**（遺伝が乗りやすい）とし、次点で異系統も許可。
3. 選抜後、確定前に「この2匹で繁殖しますか？（子のレア度予兆）」を1画面で提示 → ワンタップ確定。
4. **連打対応**: ④の長押しでクイック繁殖を連続実行（卵スロット/資源が尽きるまで）。
5. 選抜理由を一言表示（例「レア度と幸福度が最も高いペア」）＝プレイヤーが納得できる透明性。

**受入条件**: クイック繁殖1タップで妥当な2匹（高レア・高幸福・繁殖可）が選ばれ、確定できる。長押しで連続繁殖できる。

- ボス頻度カーブ・ティア倍率（§①表）は初期値。**難易度が「作業」にならないよう、ティアが上がっても撃退所要時間は概ね一定**を目標にチューニング（HP増に対し味方/設備で火力が伸びる前提）。

- 自動補給/自動給餌のコストは通常と同等（割引もペナルティも付けない）。
- 味方Lvアップ素材の要求量は「1体を数日で最大」を目安。
- 新設備の効果値はインフレを避け、シナジー前提で単体は控えめに。
- **KPI: ランク30以降、少なくとも数ウェーブに1回は「新しい対処 or 新しい発見」が起きること。**

## 7. テスト項目

- [ ] 長押しで購入/給餌/繁殖が加速連続実行され、資源枯渇で自動停止する
- [ ] 繁殖が系統→個体の二段階で選べ、100匹規模でも破綻しない
- [ ] クイック繁殖が妥当な2匹を選び、長押し連続にも対応する
- [ ] R30/60/100でショップ単位が繰り上がり、R100で自動補給が動く
- [ ] ランク30以降、毎回ボスが出て5回に1回Eliteが金縁で出る
- [ ] ランクを10跨ぐとHP/攻撃/見た目が段階的に強化される（詰みは発生しない）
- [ ] 新ボス5種が各々固有の狙い（ゴールデン/卵/生産停止/毒/減速）で動く
- [ ] 各ボスの弱点設備/味方があると明確に有利になる
- [ ] 味方6体が入手でき、対応ボスへ有利、Lvで強化される
- [ ] 設備20種が解放ランク順に設置でき、6シナジーが重複適用される
- [ ] ステージ6〜10が順に解放され、各々に固有の背景/敵/設備/レア個体がある
- [ ] 称号/実績/図鑑コンプ/統計が既存データ集計で正しく表示される
- [ ] 放浪商人/デイリー/イベント/伝説個体が新ルール暗記なしで機能する
- [ ] スマホ実機で誤タップが減り、30秒無操作でも眺めていられる
- [ ] 既存のセーブデータが破損せず読み込める（新フィールドはデフォルト補完）

## 8. 完成条件

1. **中盤（R30〜59）**: 毎回ボス＋ティア強化＋新ボスにより、ウェーブごとに対処が変わり反復感がない。
2. **終盤（R60〜90+）**: 新ステージ・設備シナジー・味方収集・伝説狙いという**複数の並行目標**が常に走っている。
3. **操作負荷が増えていない**: 長押し/クイック繁殖/自動補給で、頭数が増えても操作回数はむしろ減っている。
4. **新ルールを増やしていない**: 追加要素はすべて既存システムの再結合・再スキン・集計で成立している（プレイヤーの暗記事項ゼロ）。
5. **KPIを満たす**: 「毎回新しい発見がある」「ワクワクが増えた」「難しくはなっていない」がプレイテストで確認できる。
